# Установка и Интеграция TiaMcpServer

В этом руководстве описан процесс установки и интеграции предварительно скомпилированного `TiaMcpServer` в ваши любимые AI-ассистенты (Claude Code, Claude Desktop, Codex или Antigravity 2.0).

## 1. Установка

Папка `TiaMcpServer` уже содержит всё необходимое для запуска сервера.

1. Переместите папку `TiaMcpServer` в удобное для вас постоянное место на вашем ПК. Рекомендуемый стандартный путь:
   `C:\Users\<ВашеИмяПользователя>\AppData\Local\TiaMcpServer\`
2. Запомните этот путь, так как вам понадобится указать точный путь к файлу `TiaMcpServer.exe` на этапах интеграции ниже.

---

## 2. Интеграция с Claude Code (CLI)

[Claude Code](https://github.com/anthropics/claude-code) изначально поддерживает MCP серверы через свой конфигурационный интерфейс CLI.

Выполните следующую команду в терминале, убедившись, что указан правильный путь к `TiaMcpServer.exe`:

```bash
claude mcp add tia-mcp-server -- C:\Users\<ВашеИмяПользователя>\AppData\Local\TiaMcpServer\TiaMcpServer.exe
```

Эта команда автоматически настроит Claude Code для запуска и общения с `TiaMcpServer` через `stdio`. Вы можете проверить работоспособность, запустив `claude` и попросив его: `"Используй tia-mcp-server: выполни doctor и покажи результат"`.

---

## 3. Интеграция с Claude Desktop

Чтобы использовать `TiaMcpServer` напрямую в приложении Claude Desktop:

1. Откройте файл конфигурации Claude Desktop, расположенный по пути:
   `%APPDATA%\Claude\claude_desktop_config.json`
2. Добавьте сервер в объект `mcpServers`, указав правильный путь:

```json
{
  "mcpServers": {
    "tia-mcp-server": {
      "command": "C:\\Users\\<ВашеИмяПользователя>\\AppData\\Local\\TiaMcpServer\\TiaMcpServer.exe",
      "args": []
    }
  }
}
```
3. Полностью закройте и перезапустите Claude Desktop.

## 4. Интеграция с Codex

[Codex](https://developers.openai.com/codex) (настольное приложение и CLI) хранит MCP-серверы в одном файле —
`C:\Users\<ВашеИмяПользователя>\.codex\config.toml`. Все три способа ниже делают в нём одну и ту же запись.

### Вариант А: Настройки настольного приложения

1. Откройте **Настройки → Плагины**, нажмите **Добавить** и выберите **Добавить сервер MCP**.
2. В форме «Подключиться к пользовательскому MCP» заполните:
   - **Имя** — например, `tiamcpserver`;
   - **Тип** — `STDIO` (не «Потоковая передача HTTP»);
   - **Команда на запуск** — полный путь к `TiaMcpServer.exe`;
   - **Аргументы** — пусто. Параметры запуска вносятся по одному в поле: `--read-only` — одно
     поле, `--tia-major-version` и `20` — два; новое поле даёт кнопка **Добавить аргумент**;
   - **Переменные окружения** — не нужны.
3. Сервер появится на вкладке **MCP** в списке **Серверы** с переключателем. Переключатель
   выключает сервер, не удаляя его, — пользуйтесь им перед обновлением файлов сервера.
   Значок шестерёнки открывает ту же форму для правки; там же кнопка **Удалить**.

### Вариант Б: Командная строка

```bash
codex mcp add tiamcpserver -- C:\Users\<ВашеИмяПользователя>\AppData\Local\TiaMcpServer\TiaMcpServer.exe
```

`codex mcp list` покажет сервер со статусом `enabled`; `codex mcp remove tiamcpserver` удаляет его.

### Вариант В: Файл конфигурации

Добавьте в `C:\Users\<ВашеИмяПользователя>\.codex\config.toml`:

```toml
[mcp_servers.tiamcpserver]
enabled = true
command = 'C:\Users\<ВашеИмяПользователя>\AppData\Local\TiaMcpServer\TiaMcpServer.exe'
args = []
```

Путь взят в одинарные кавычки: так TOML принимает обратные косые черты как есть. Параметры
запуска идут в `args`, например `args = ["--read-only"]`.

После любого из трёх способов начните новую сессию Codex и проверьте работу запросом
`"Используй tiamcpserver: запусти doctor и покажи результат"`.

## 5. Интеграция с Antigravity 2.0 (IDE)

Antigravity 2.0 настраивает MCP серверы через файл `mcp.json`. Вы можете настроить его **Глобально** (для всех ваших проектов) или **Для отдельной рабочей области (Workspace)**.

### Вариант А: Глобальная конфигурация
1. Откройте или создайте файл `C:\Users\<ВашеИмяПользователя>\.gemini\config\mcp.json`.
2. Добавьте следующий JSON-код (не забудьте изменить путь, если вы сохранили папку в другом месте):

```json
{
  "servers": {
    "tia-mcp-server": {
      "type": "stdio",
      "command": "C:\\Users\\<ВашеИмяПользователя>\\AppData\\Local\\TiaMcpServer\\TiaMcpServer.exe",
      "args": []
    }
  }
}
```

### Вариант Б: Конфигурация рабочей области (VS Code / Antigravity)
1. В корне вашего проекта откройте или создайте файл `.vscode/mcp.json`.
2. Вставьте тот же JSON-код, что указан выше.

Перезапустите агент Antigravity или IDE, и инструменты `tia-mcp-server` станут доступны в вашем контексте!

## Параметры запуска

Параметры передаются в `args` конфигурации клиента, например `"args": ["--read-only"]` (в Codex: `args = ["--read-only"]`).

| Параметр | Назначение |
| --- | --- |
| `--tia-major-version <n>` | Версия TIA Portal. По умолчанию `21`. |
| `--read-only` | Не регистрировать инструменты, изменяющие проект. Без параметра запись доступна. |
| `--logging <1\|2\|3>` | `1` — stderr, `2` — отладочный вывод, `3` — журнал событий Windows. |
| `--doctor` | Вывести отчёт об окружении и завершиться. |
| `--debug-tools` | Зарегистрировать отладочные инструменты разработки сервера. |

TIA Portal должен быть запущен до подключения: инструмент `connect` сам его не стартует
(кроме вызова с `startIfNotRunning=true`). Управление PLCSIM вынесено в отдельный MCP-сервер;
для `download_to_plc` цель загрузки должна быть запущена заранее.

## Обновление

Файлы сервера заняты, пока клиент MCP запущен. Перед заменой содержимого папки `TiaMcpServer`
закройте клиент (или отключите сервер в его настройках). После первого запуска новой сборки
TIA Portal спросит разрешение на доступ Openness — его нужно подтвердить.
