# Инструменты MCP-сервера TIA Portal

`CloseProject`: Закрыть текущий проект/сессию TIA-Portal
`CompileBlock`: Скомпилировать программный блок. Возвращает результат компиляции с ошибками или предупреждениями.
`CompileSoftware`: Скомпилировать всю программу ПЛК. Возвращает детальный результат компиляции с ошибками и предупреждениями по каждому объекту.
`ConfigureHmiScreenItem`: Настроить элемент (например, размеры, текст, привязку ProcessValue) на заданном экране HMI.
`ConfigureHmiTrendCompanion`: Привязать HmiTrendCompanion к HmiTrendControl. Только для WinCC Unified.
`ConfigureHmiTrendControl`: Добавить тренд/перо в HmiTrendControl и привязать к источнику данных (например, тегу). Только для WinCC Unified.
`Connect`: Подключиться к TIA-Portal
`ConnectSubnet`: Подключить сетевой интерфейс к подсети (создает подсеть PN/IE, если она не существует).
`ConnectToIoSystem`: Подключить сетевой интерфейс IO устройства к существующей IO системе.
`CopyBlock`: Скопировать программный блок в другую группу блоков того же ПЛК. Реализовано через экспорт и импорт, так как Openness не имеет встроенной операции копирования.
`CopyType`: Скопировать тип данных ПЛК (UDT) в другую группу типов того же ПЛК. Реализовано через экспорт и импорт.
`CreateBlockGroup`: Создать группу (папку) внутри программных блоков ПЛК.
`CreateExternalSourceFromFile`: Добавить исходный файл (например, SCL-файл) из файловой системы во внешние исходные файлы ПЛК.
`CreateExternalSourceGroup`: Создать группу (папку) во внешних исходных файлах ПЛК.
`CreateFB`: Создать пустой функциональный блок (FB).
`CreateHardwareDevice`: Создать новое аппаратное устройство (ПЛК, HMI, станция ET200 и т.д.) на уровне проекта.
`CreateHmiScreen`: Создать новый экран HMI на заданном HMI-устройстве.
`CreateHmiScreenItem`: Создать элемент (например, HmiButton, HmiIOField, HmiFaceplate) на заданном экране HMI.
`CreateInstanceDB`: Создать экземплярный блок данных (Instance DB) для существующего функционального блока.
`CreateIoSystem`: Создать PROFINET IO систему для сетевого интерфейса ПЛК.
`CreateSclBlock`: Создать блок напрямую из текстового исходного кода SCL.
`CreateTag`: Создать ПЛК тег в таблице тегов.
`CreateTagTable`: Создать таблицу тегов ПЛК в группе таблиц тегов.
`CreateTagTableGroup`: Создать группу (папку) внутри тегов ПЛК.
`CreateTypeGroup`: Создать группу (папку) внутри типов данных ПЛК (UDT).
`CreateUserConstant`: Создать пользовательскую константу в таблице тегов. (Системные константы доступны только для чтения).
`CreateWatchTable`: Создать таблицу наблюдения (Watch table) ПЛК. (Таблицы принудительных значений (Force) создавать нельзя).
`CreateWatchTableGroup`: Создать группу (папку) в таблицах наблюдения и принудительных значений ПЛК.
`DebugReflect`: Получить рефлексию (структуру) сборки (для отладки).
`DebugScreenItem`: Получить рефлексию (структуру) элемента экрана (для отладки).
`DeleteBlock`: Удалить программный блок. Блоки с защитой know-how отклоняются.
`DeleteBlockGroup`: Удалить группу (папку) блоков и все её содержимое.
`DeleteExternalSource`: Удалить внешний исходный файл из ПЛК.
`DeleteExternalSourceGroup`: Удалить группу (папку) внешних исходных файлов и все её содержимое.
`DeleteHardwareDevice`: Удалить аппаратное устройство (ПЛК, HMI и т.д.) из проекта.
`DeleteHmiScreen`: Удалить экран HMI.
`DeleteHmiScreenItem`: Удалить элемент с заданного экрана HMI.
`DeleteTag`: Удалить ПЛК тег из таблицы тегов.
`DeleteTagTable`: Удалить таблицу тегов ПЛК вместе со всеми тегами и пользовательскими константами.
`DeleteTagTableGroup`: Удалить группу (папку) таблиц тегов и все её содержимое.
`DeleteType`: Удалить тип данных ПЛК (UDT).
`DeleteTypeGroup`: Удалить группу (папку) типов данных ПЛК и все её содержимое.
`DeleteUserConstant`: Удалить пользовательскую константу из таблицы тегов.
`DeleteWatchTable`: Удалить таблицу наблюдения ПЛК со всеми её записями.
`DeleteWatchTableGroup`: Удалить группу (папку) таблиц наблюдения и все её содержимое.
`Disconnect`: Отключиться от TIA-Portal.
`DisconnectSubnet`: Отключить сетевой интерфейс от текущей подсети.
`Doctor`: Выполнить диагностику окружения TIA-Portal (подключение, открытый проект, установленные версии, членство в группе Openness).
`DownloadToPlc`: Загрузить конфигурацию оборудования и/или программное обеспечение в ПЛК.
`ExportAsDocuments`: Экспортировать блок как документы (.s7dcl/.s7res).
`ExportBlocksAsDocuments`: Экспортировать все программные блоки как документы (.s7dcl/.s7res).
`ExportPlcAsDocuments`: Экспортировать всё ПО ПЛК как документы.
`ExportSourceBlock`: Экспортировать программный блок в исходный код (файл источника).
`ExportSourceBlocks`: Экспортировать несколько программных блоков в исходный код (файлы источников).
`ExportSourceType`: Экспортировать тип данных ПЛК (UDT) в исходный код (файл источника).
`ExportSourceTypes`: Экспортировать несколько типов данных ПЛК (UDT) в исходный код (файлы источников).
`ExportTypeAsDocuments`: Экспортировать тип данных ПЛК (UDT) как документы (.s7dcl/.s7res).
`ExportTypesAsDocuments`: Экспортировать несколько типов данных ПЛК (UDT) как документы (.s7dcl/.s7res).
`ExportXmlBlock`: Экспортировать программный блок в формат XML.
`ExportXmlBlocks`: Экспортировать несколько программных блоков в формат XML.
`ExportXmlTagTable`: Экспортировать таблицу тегов ПЛК в формат XML.
`ExportXmlType`: Экспортировать тип данных ПЛК в формат XML.
`ExportXmlTypes`: Экспортировать несколько типов данных ПЛК в формат XML.
`ExportXmlWatchTable`: Экспортировать таблицу наблюдения ПЛК в формат XML.
`FindInCode`: Поиск текста или регулярного выражения в исходном коде программных блоков и типов данных ПЛК.
`GenerateSources`: Сгенерировать источники.
`GetBlockInfo`: Получить информацию о программном блоке.
`GetBlockInterface`: Получить интерфейс (входы, выходы, InOut) программного блока.
`GetBlocks`: Получить список всех программных блоков ПЛК.
`GetBlockSource`: Получить исходный код программного блока.
`GetBlocksWithHierarchy`: Получить список программных блоков с учетом их иерархии (папок).
`GetConstants`: Получить пользовательские константы ПЛК.
`GetCrossReferences`: Получить перекрестные ссылки для ПО ПЛК, блока, типа, тега или таблицы тегов.
`GetDeviceInfo`: Получить подробную информацию об аппаратном устройстве по его пути.
`GetDeviceItemInfo`: Получить подробную информацию об элементе устройства (модуле) по его пути.
`GetDownloadTargets`: Получить доступные интерфейсы загрузки (Download targets) для ПЛК.
`GetExternalSourceInfo`: Получить информацию о внешнем исходном файле ПЛК.
`GetExternalSources`: Получить список внешних исходных файлов ПЛК.
`GetForceTables`: Получить список таблиц принудительных значений (Force tables) ПЛК.
`GetHardwareTopology`: Получить иерархию (топологию) оборудования проекта, включая устройства, модули и подсети.
`GetHmiConnections`: Получить список всех подключений HMI к ПЛК и их атрибуты.
`GetHmiScreenItems`: Получить список всех элементов (кнопок, графики и т.д.) на заданном экране HMI.
`GetHmiScreens`: Получить список всех экранов в целевом HMI устройстве.
`GetHmiTags`: Получить список всех тегов в целевом HMI устройстве.
`GetLibraries`: Открыть глобальную библиотеку (.al1x) в текущей сессии TIA Portal.
`GetLibraryFaceplates`: Получить полный словарь свойств, динамически доступных для фейсплейта из библиотеки через Openness.
`GetMasterCopies`: Получить список мастер-копий (Master Copies) из библиотеки.
`GetPlcSummary`: Получить сводную статистику по ПЛК (количество блоков, тегов, типы языков программирования, ошибки компиляции).
`GetProject`: Получить доступ к открытому проекту/сессии TIA-Portal.
`GetSoftwareInfo`: Получить базовую информацию о программном обеспечении ПЛК.
`GetSoftwareTree`: Получить структуру ПО ПЛК в виде дерева (включает блоки, типы, теги, таблицы и источники).
`GetState`: Получить состояние подключения и среды выполнения TIA Portal.
`GetTagInfo`: Получить информацию о конкретном ПЛК теге.
`GetTags`: Получить список всех тегов ПЛК.
`GetTagTableInfo`: Получить таблицу тегов ПЛК вместе с ее содержимым.
`GetTagTables`: Получить список таблиц тегов ПЛК.
`GetTypeInfo`: Получить информацию о типе данных ПЛК (UDT).
`GetTypes`: Получить список всех типов данных ПЛК.
`GetTypeSource`: Получить исходный код типа данных ПЛК.
`GetWatchTableInfo`: Получить информацию о таблице наблюдения ПЛК, включая все её переменные и параметры отображения.
`GetWatchTables`: Получить список таблиц наблюдения ПЛК.
`ImportAllSources`: Импортировать все внешние источники.
`ImportAllSourcesKeepOnError`: Импортировать все внешние источники, сохраняя успешно сгенерированные объекты даже при наличии ошибок.
`ImportBlocksFromDocuments`: Импортировать программные блоки из документов (.s7dcl/.s7res).
`ImportFromDocuments`: Импортировать объект из документов (.s7dcl/.s7res).
`ImportSourceBlocks`: Скомпилировать внешний исходный файл в программные блоки и типы данных ПЛК.
`ImportSources`: Скомпилировать исходные файлы (*.db, *.awl, *.scl, *.udt) из файлового дерева обратно в проект.
`ImportTypeFromDocuments`: Импортировать тип данных ПЛК из документов.
`ImportTypesFromDocuments`: Импортировать несколько типов данных ПЛК из документов.
`ImportWatchTable`: Импортировать таблицу наблюдения из XML файла.
`ImportXmlBlock`: Импортировать программный блок из XML файла.
`ImportXmlTagTable`: Импортировать таблицу тегов из XML файла.
`ImportXmlType`: Импортировать тип данных ПЛК из XML файла.
`InstantiateMasterCopy`: Создать экземпляр мастер-копии (Master Copy) из библиотеки в проекте (например, блок или тип данных).
`MoveBlock`: Переместить программный блок в другую группу.
`MoveType`: Переместить тип данных ПЛК (UDT) в другую группу.
`OpenGlobalLibrary`: Открыть глобальную библиотеку (.al1x) в текущей сессии TIA Portal.
`OpenProject`: Открыть существующий проект или сессию TIA-Portal.
`OpenTiaProject`: Подключиться к TIA Portal (если еще не подключено) и открыть заданный проект/сессию.
`plcsim_batch_read`: Пакетное чтение значений нескольких тегов симуляции за одну операцию.
`plcsim_batch_write`: Пакетная запись значений в несколько тегов симуляции за одну операцию.
`plcsim_connect`: Подключиться к виртуальному контроллеру PLCSim.
`plcsim_create_instance`: Создать новый виртуальный контроллер PLCSim.
`plcsim_delete_instance`: Удалить существующий экземпляр PLCSim.
`plcsim_delete_profile`: Удалить сохраненный профиль симуляции PLCSim.
`plcsim_disconnect`: Отключиться от симуляции PLCSim.
`plcsim_get_instance_config`: Получить конфигурацию экземпляра PLCSim.
`plcsim_get_instance_state`: Получить текущее состояние экземпляра PLCSim.
`plcsim_get_network`: Получить настройки сети симуляции.
`plcsim_get_runtime_config`: Получить конфигурацию времени выполнения симуляции.
`plcsim_get_simulation_state`: Получить общее состояние симуляции.
`plcsim_list_instances`: Получить список всех доступных экземпляров PLCSim.
`plcsim_list_profiles`: Получить список всех сохраненных профилей симуляции.
`plcsim_list_tags`: Получить список всех тегов, доступных в симуляции.
`plcsim_load_profile`: Загрузить сохраненный профиль симуляции.
`plcsim_memory_reset`: Выполнить сброс памяти (Memory Reset) симулируемого ПЛК.
`plcsim_power_off`: Выключить питание симулируемого ПЛК.
`plcsim_power_on`: Включить питание симулируемого ПЛК.
`plcsim_read_tag`: Прочитать значение одного тега симуляции.
`plcsim_refresh_tags`: Обновить список тегов из симуляции.
`plcsim_run`: Перевести симулируемый ПЛК в режим RUN.
`plcsim_save_profile`: Сохранить текущее состояние симуляции как профиль.
`plcsim_set_instance_config`: Настроить параметры экземпляра PLCSim.
`plcsim_set_network`: Настроить сетевые параметры для симуляции.
`plcsim_set_runtime_config`: Настроить параметры времени выполнения для симуляции.
`plcsim_set_runtime_port`: Установить порт связи времени выполнения.
`plcsim_set_widget_value`: Установить значение элемента виджета симуляции.
`plcsim_start_runtime`: Запустить движок времени выполнения PLCSim.
`plcsim_start_simulation`: Запустить симуляцию PLCSim.
`plcsim_status`: Получить общий статус PLCSim.
`plcsim_stop`: Перевести симулируемый ПЛК в режим STOP.
`plcsim_stop_simulation`: Остановить запущенную симуляцию PLCSim.
`plcsim_update_profile`: Обновить существующий профиль симуляции.
`plcsim_write_tag`: Записать значение в тег симуляции.
`PlugHardwareModule`: Добавить (установить) новый аппаратный модуль в существующее устройство на определенную позицию.
`PreviewImport`: Предпросмотр результатов импорта (проверка конфликтов и возможных перезаписей перед фактическим импортом).
`RenameBlock`: Переименовать программный блок. Блоки с защитой know-how отклоняются.
`RenameTagTable`: Переименовать таблицу тегов ПЛК.
`RenameType`: Переименовать тип данных ПЛК (UDT). Типы с защитой know-how отклоняются.
`RenameWatchTable`: Переименовать таблицу наблюдения ПЛК.
`ResolveObjectPath`: Преобразовать простое имя объекта в полный путь, ища среди блоков, типов данных, тегов, таблиц и внешних источников.
`SaveAsProject`: Сохранить текущий проект/сессию TIA-Portal под новым именем.
`SaveProject`: Сохранить текущий проект/сессию TIA-Portal.
`SetHmiScreenItemProperty`: Установить произвольное свойство элемента экрана по его точному имени (например, 'BackColor'). Если имя элемента пустое - модифицирует сам экран.
`SetHmiUnifiedScreenItemEvent`: Установить обработчик события (например, Click) со скриптом JS для элемента экрана WinCC Unified.
`start_plcsim_and_download_all`: Найти PLCSIM, запустить его, дождаться инициализации и загрузить все ПЛК из проекта в виртуальный адаптер PLCSIM.
`UpdateTag`: Изменить одно или несколько свойств существующего тега ПЛК.
`UpdateUserConstant`: Изменить имя, тип данных или значение пользовательской константы.
`WhereUsed`: Показать, где используется (Cross-references) тег, блок, тип данных или таблица тегов (в виде простого списка).
