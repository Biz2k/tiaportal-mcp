# Инструменты MCP-сервера TIA Portal

`close_project`: Закрыть текущий проект/сессию TIA-Portal
`compile_block`: Скомпилировать программный блок. Возвращает результат компиляции с ошибками или предупреждениями.
`compile_software`: Скомпилировать всю программу ПЛК. Возвращает детальный результат компиляции с ошибками и предупреждениями.
`configure_hmi_screen_item`: Настроить элемент (например, размеры, текст, привязку ProcessValue) на заданном экране HMI.
`configure_unified_trend_companion`: Привязать HmiTrendCompanion к HmiTrendControl. Только для WinCC Unified.
`configure_unified_trend_control`: Добавить тренд/перо в HmiTrendControl и привязать к источнику данных. Только для WinCC Unified.
`connect`: Подключиться к TIA-Portal
`connect_subnet`: Подключить сетевой интерфейс к подсети (создает подсеть PN/IE, если она не существует).
`connect_to_io_system`: Подключить сетевой интерфейс IO устройства к существующей IO системе.
`copy_block`: Скопировать программный блок в другую группу блоков того же ПЛК. Реализовано через экспорт и импорт.
`copy_type`: Скопировать тип данных ПЛК (UDT) в другую группу типов того же ПЛК. Реализовано через экспорт и импорт.
`create_block_group`: Создать группу (папку) внутри программных блоков ПЛК.
`create_external_source_from_file`: Добавить исходный файл (например, SCL-файл) из файловой системы во внешние исходные файлы ПЛК.
`create_external_source_group`: Создать группу (папку) во внешних исходных файлах ПЛК.
`create_fb`: Создать пустой функциональный блок (FB).
`create_hardware_device`: Создать новое аппаратное устройство (ПЛК, HMI, станция ET200 и т.д.) на уровне проекта.
`create_hmi_screen`: Создать новый экран HMI на заданном HMI-устройстве.
`create_hmi_screen_item`: Создать элемент (например, HmiButton, HmiIOField, HmiFaceplate) на заданном экране HMI.
`create_instance_db`: Создать экземплярный блок данных (Instance DB) для существующего функционального блока.
`create_io_system`: Создать PROFINET IO систему для сетевого интерфейса ПЛК.
`create_scl_block`: Создать блок напрямую из текстового исходного кода SCL.
`create_tag`: Создать ПЛК тег в таблице тегов.
`create_tag_table`: Создать таблицу тегов ПЛК в группе таблиц тегов.
`create_tag_table_group`: Создать группу (папку) внутри тегов ПЛК.
`create_type_group`: Создать группу (папку) внутри типов данных ПЛК (UDT).
`create_user_constant`: Создать пользовательскую константу в таблице тегов. (Системные константы доступны только для чтения).
`create_watch_table`: Создать таблицу наблюдения (Watch table) ПЛК. (Таблицы принудительных значений (Force) создавать нельзя).
`create_watch_table_group`: Создать группу (папку) в таблицах наблюдения и принудительных значений ПЛК.
`debug_reflect`: Получить рефлексию (структуру) сборки (для отладки).
`debug_screen_item`: Получить рефлексию (структуру) элемента экрана (для отладки).
`delete_block`: Удалить программный блок. Блоки с защитой know-how отклоняются.
`delete_block_group`: Удалить группу (папку) блоков и все её содержимое.
`delete_external_source`: Удалить внешний исходный файл из ПЛК.
`delete_external_source_group`: Удалить группу (папку) внешних исходных файлов и все её содержимое.
`delete_hardware_device`: Удалить аппаратное устройство (ПЛК, HMI и т.д.) из проекта.
`delete_hmi_screen`: Удалить экран HMI.
`delete_hmi_screen_item`: Удалить элемент с заданного экрана HMI.
`delete_tag`: Удалить ПЛК тег из таблицы тегов.
`delete_tag_table`: Удалить таблицу тегов ПЛК вместе со всеми тегами и пользовательскими константами.
`delete_tag_table_group`: Удалить группу (папку) таблиц тегов и все её содержимое.
`delete_type`: Удалить тип данных ПЛК (UDT).
`delete_type_group`: Удалить группу (папку) типов данных ПЛК и все её содержимое.
`delete_user_constant`: Удалить пользовательскую константу из таблицы тегов.
`delete_watch_table`: Удалить таблицу наблюдения ПЛК со всеми её записями.
`delete_watch_table_group`: Удалить группу (папку) таблиц наблюдения и все её содержимое.
`disconnect`: Отключиться от TIA-Portal.
`disconnect_subnet`: Отключить сетевой интерфейс от текущей подсети.
`doctor`: Выполнить диагностику окружения TIA-Portal (подключение, открытый проект, установленные версии, членство в группе Openness).
`download_to_plc`: Загрузить конфигурацию оборудования и/или программное обеспечение в ПЛК.
`export_as_documents`: Экспортировать блок как документы (.s7dcl/.s7res).
`export_blocks_as_documents`: Экспортировать все программные блоки как документы (.s7dcl/.s7res).
`export_plc_as_documents`: Экспортировать всё ПО ПЛК как документы.
`export_source_block`: Экспортировать программный блок в исходный код (файл источника).
`export_source_blocks`: Экспортировать несколько программных блоков в исходный код (файлы источников).
`export_source_type`: Экспортировать тип данных ПЛК (UDT) в исходный код (файл источника).
`export_source_types`: Экспортировать несколько типов данных ПЛК (UDT) в исходный код (файлы источников).
`export_type_as_documents`: Экспортировать тип данных ПЛК (UDT) как документы (.s7dcl/.s7res).
`export_types_as_documents`: Экспортировать несколько типов данных ПЛК (UDT) как документы (.s7dcl/.s7res).
`export_xml_block`: Экспортировать программный блок в формат XML.
`export_xml_blocks`: Экспортировать несколько программных блоков в формат XML.
`export_xml_tag_table`: Экспортировать таблицу тегов ПЛК в формат XML.
`export_xml_type`: Экспортировать тип данных ПЛК в формат XML.
`export_xml_types`: Экспортировать несколько типов данных ПЛК в формат XML.
`export_xml_watch_table`: Экспортировать таблицу наблюдения ПЛК в формат XML.
`find_in_code`: Поиск текста или регулярного выражения в исходном коде программных блоков и типов данных ПЛК.
`generate_sources`: Сгенерировать источники.
`get_block_info`: Получить информацию о программном блоке.
`get_block_interface`: Получить интерфейс (входы, выходы, InOut) программного блока.
`get_blocks`: Получить список всех программных блоков ПЛК.
`get_block_source`: Получить исходный код программного блока.
`get_blocks_with_hierarchy`: Получить список программных блоков с учетом их иерархии (папок).
`get_constants`: Получить пользовательские константы ПЛК.
`get_cross_references`: Получить перекрестные ссылки для ПО ПЛК, блока, типа, тега или таблицы тегов.
`get_device_info`: Получить подробную информацию об аппаратном устройстве по его пути.
`get_device_item_info`: Получить подробную информацию об элементе устройства (модуле) по его пути.
`get_download_targets`: Получить доступные интерфейсы загрузки (Download targets) для ПЛК.
`get_external_source_info`: Получить информацию о внешнем исходном файле ПЛК.
`get_external_sources`: Получить список внешних исходных файлов ПЛК.
`get_force_tables`: Получить список таблиц принудительных значений (Force tables) ПЛК.
`get_hardware_topology`: Получить иерархию (топологию) оборудования проекта, включая устройства, модули и подсети.
`get_hmi_connections`: Получить список всех подключений HMI к ПЛК и их атрибуты.
`get_hmi_screen_items`: Получить список всех элементов (кнопок, графики и т.д.) на заданном экране HMI.
`get_hmi_screens`: Получить список всех экранов в целевом HMI устройстве.
`get_hmi_tags`: Получить список всех тегов в целевом HMI устройстве.
`get_libraries`: Открыть глобальную библиотеку (.al1x) в текущей сессии TIA Portal.
`get_library_faceplates`: Получить полный словарь свойств, динамически доступных для фейсплейта из библиотеки через Openness.
`get_master_copies`: Получить список мастер-копий (Master Copies) из библиотеки.
`get_plc_summary`: Получить сводную статистику по ПЛК (количество блоков, тегов, типы языков программирования, ошибки компиляции).
`get_project`: Получить доступ к открытому проекту/сессии TIA-Portal.
`get_software_info`: Получить базовую информацию о программном обеспечении ПЛК.
`get_software_tree`: Получить структуру ПО ПЛК в виде дерева (включает блоки, типы, теги, таблицы и источники).
`get_state`: Получить состояние подключения и среды выполнения TIA Portal.
`get_tag_info`: Получить информацию о конкретном ПЛК теге.
`get_tags`: Получить список всех тегов ПЛК.
`get_tag_table_info`: Получить таблицу тегов ПЛК вместе с ее содержимым.
`get_tag_tables`: Получить список таблиц тегов ПЛК.
`get_type_info`: Получить информацию о типе данных ПЛК (UDT).
`get_types`: Получить список всех типов данных ПЛК.
`get_type_source`: Получить исходный код типа данных ПЛК.
`get_watch_table_info`: Получить информацию о таблице наблюдения ПЛК, включая все её переменные и параметры отображения.
`get_watch_tables`: Получить список таблиц наблюдения ПЛК.
`import_all_sources`: Импортировать все внешние источники.
`import_all_sources_keep_on_error`: Импортировать все внешние источники, сохраняя успешно сгенерированные объекты даже при наличии ошибок.
`import_blocks_from_documents`: Импортировать программные блоки из документов (.s7dcl/.s7res).
`import_from_documents`: Импортировать объект из документов (.s7dcl/.s7res).
`import_source_blocks`: Скомпилировать внешний исходный файл в программные блоки и типы данных ПЛК.
`import_sources`: Скомпилировать исходные файлы (*.db, *.awl, *.scl, *.udt) из файлового дерева обратно в проект.
`import_type_from_documents`: Импортировать тип данных ПЛК из документов.
`import_types_from_documents`: Импортировать несколько типов данных ПЛК из документов.
`import_watch_table`: Импортировать таблицу наблюдения из XML файла.
`import_xml_block`: Импортировать программный блок из XML файла.
`import_xml_tag_table`: Импортировать таблицу тегов из XML файла.
`import_xml_type`: Импортировать тип данных ПЛК из XML файла.
`instantiate_master_copy`: Создать экземпляр мастер-копии (Master Copy) из библиотеки в проекте (например, блок или тип данных).
`move_block`: Переместить программный блок в другую группу.
`move_type`: Переместить тип данных ПЛК (UDT) в другую группу.
`open_global_library`: Открыть глобальную библиотеку (.al1x) в текущей сессии TIA Portal.
`open_project`: Открыть существующий проект или сессию TIA-Portal.
`open_tia_project`: Подключиться к TIA Portal (если еще не подключено) и открыть заданный проект/сессию.
`plug_hardware_module`: Добавить (установить) новый аппаратный модуль в существующее устройство на определенную позицию.
`preview_import`: Предпросмотр результатов импорта (проверка конфликтов и возможных перезаписей перед фактическим импортом).
`rename_block`: Переименовать программный блок. Блоки с защитой know-how отклоняются.
`rename_tag_table`: Переименовать таблицу тегов ПЛК.
`rename_type`: Переименовать тип данных ПЛК (UDT). Типы с защитой know-how отклоняются.
`rename_watch_table`: Переименовать таблицу наблюдения ПЛК.
`resolve_object_path`: Преобразовать простое имя объекта в полный путь, ища среди блоков, типов данных, тегов, таблиц и внешних источников.
`save_as_project`: Сохранить текущий проект/сессию TIA-Portal под новым именем.
`save_project`: Сохранить текущий проект/сессию TIA-Portal.
`set_hmi_screen_item_property`: Установить произвольное свойство элемента экрана по его точному имени (например, 'BackColor'). Если имя элемента пустое - модифицирует сам экран.
`set_hmi_unified_screen_item_event`: Установить обработчик события (например, Click) со скриптом JS для элемента экрана WinCC Unified.
`update_tag`: Изменить одно или несколько свойств существующего тега ПЛК.
`update_user_constant`: Изменить имя, тип данных или значение пользовательской константы.
`where_used`: Показать, где используется (Cross-references) тег, блок, тип данных или таблица тегов (в виде простого списка).
