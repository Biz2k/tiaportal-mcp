# Инструменты MCP-сервера TIA Portal

`close_project`: Закрыть текущий проект/сессию TIA-Portal
`plc_compile_block`: Скомпилировать программный блок. Возвращает результат компиляции с ошибками или предупреждениями.
`plc_compile_software`: Скомпилировать всю программу ПЛК. Возвращает детальный результат компиляции с ошибками и предупреждениями.
`hmi_configure_screen_item`: Настроить элемент (например, размеры, текст, привязку ProcessValue) на заданном экране HMI.
`hmi_configure_unified_trend_companion`: Привязать HmiTrendCompanion к HmiTrendControl. Только для WinCC Unified.
`hmi_configure_unified_trend_control`: Добавить тренд/перо в HmiTrendControl и привязать к источнику данных. Только для WinCC Unified.
`connect`: Подключиться к TIA-Portal
`net_connect_subnet`: Подключить сетевой интерфейс к подсети (создает подсеть PN/IE, если она не существует).
`net_connect_to_io_system`: Подключить сетевой интерфейс IO устройства к существующей IO системе.
`plc_copy_block`: Скопировать программный блок в другую группу блоков того же ПЛК. Реализовано через экспорт и импорт.
`plc_copy_type`: Скопировать тип данных ПЛК (UDT) в другую группу типов того же ПЛК. Реализовано через экспорт и импорт.
`plc_create_block_group`: Создать группу (папку) внутри программных блоков ПЛК.
`plc_create_external_source`: Добавить исходный файл (например, SCL-файл) из файловой системы во внешние исходные файлы ПЛК.
`plc_create_external_source_group`: Создать группу (папку) во внешних исходных файлах ПЛК.
`plc_create_fb`: Создать пустой функциональный блок (FB).
`hw_create_device`: Создать новое аппаратное устройство (ПЛК, HMI, станция ET200 и т.д.) на уровне проекта.
`hmi_create_screen`: Создать новый экран HMI на заданном HMI-устройстве.
`plc_create_instance_db`: Создать экземплярный блок данных (Instance DB) для существующего функционального блока.
`net_create_io_system`: Создать PROFINET IO систему для сетевого интерфейса ПЛК.
`plc_create_scl_block`: Создать блок напрямую из текстового исходного кода SCL.
`plc_create_tag_table`: Создать таблицу тегов ПЛК в группе таблиц тегов.
`plc_create_tag_table_group`: Создать группу (папку) внутри тегов ПЛК.
`plc_create_type_group`: Создать группу (папку) внутри типов данных ПЛК (UDT).
`plc_create_watch_table`: Создать таблицу наблюдения (Watch table) ПЛК. (Таблицы принудительных значений (Force) создавать нельзя).
`plc_create_watch_table_group`: Создать группу (папку) в таблицах наблюдения и принудительных значений ПЛК.
`hmi_debug_reflect`: Получить рефлексию (структуру) сборки (для отладки).
`hmi_debug_screen_item`: Получить рефлексию (структуру) элемента экрана (для отладки).
`plc_delete_block`: Удалить программный блок. Блоки с защитой know-how отклоняются.
`plc_delete_block_group`: Удалить группу (папку) блоков и все её содержимое.
`plc_delete_external_source`: Удалить внешний исходный файл из ПЛК.
`plc_delete_external_source_group`: Удалить группу (папку) внешних исходных файлов и все её содержимое.
`hw_delete_device`: Удалить аппаратное устройство (ПЛК, HMI и т.д.) из проекта.
`hmi_delete_screen`: Удалить экран HMI.
`plc_delete_tag_table`: Удалить таблицу тегов ПЛК вместе со всеми тегами и пользовательскими константами.
`plc_delete_tag_table_group`: Удалить группу (папку) таблиц тегов и все её содержимое.
`plc_delete_type`: Удалить тип данных ПЛК (UDT).
`plc_delete_type_group`: Удалить группу (папку) типов данных ПЛК и все её содержимое.
`plc_delete_watch_table`: Удалить таблицу наблюдения ПЛК со всеми её записями.
`plc_delete_watch_table_group`: Удалить группу (папку) таблиц наблюдения и все её содержимое.
`disconnect`: Отключиться от TIA-Portal.
`net_disconnect_subnet`: Отключить сетевой интерфейс от текущей подсети.
`doctor`: Выполнить диагностику окружения TIA-Portal (подключение, открытый проект, установленные версии, членство в группе Openness).
`download_to_plc`: Загрузить конфигурацию оборудования и/или программное обеспечение в ПЛК.
`plc_find_in_code`: Поиск текста или регулярного выражения в исходном коде программных блоков и типов данных ПЛК.
`plc_generate_sources`: Сгенерировать источники.
`plc_get_blocks`: Получить список всех программных блоков ПЛК.
`plc_get_blocks_hierarchy`: Получить список программных блоков с учетом их иерархии (папок).
`plc_get_constants`: Получить пользовательские константы ПЛК.
`plc_get_cross_references`: Получить перекрестные ссылки для ПО ПЛК, блока, типа, тега или таблицы тегов.
`hw_get_device_info`: Получить подробную информацию об аппаратном устройстве по его пути.
`get_device_item_info`: Получить подробную информацию об элементе устройства (модуле) по его пути.
`get_download_targets`: Получить доступные интерфейсы загрузки (Download targets) для ПЛК.
`plc_get_external_source_info`: Получить информацию о внешнем исходном файле ПЛК.
`plc_get_external_sources`: Получить список внешних исходных файлов ПЛК.
`plc_get_force_tables`: Получить список таблиц принудительных значений (Force tables) ПЛК.
`get_hardware_topology`: Получить иерархию (топологию) оборудования проекта, включая устройства, модули и подсети.
`hmi_get_connections`: Получить список всех подключений HMI к ПЛК и их атрибуты.
`hmi_get_screen_items`: Получить список всех элементов (кнопок, графики и т.д.) на заданном экране HMI.
`hmi_get_screens`: Получить список всех экранов в целевом HMI устройстве.
`hmi_get_tags`: Получить список всех тегов в целевом HMI устройстве.
`get_libraries`: Открыть глобальную библиотеку (.al1x) в текущей сессии TIA Portal.
`hmi_create_faceplate_instance`: Добавить экземпляр Faceplate на экран HMI и связать его с библиотечным типом.
`hmi_get_library_types`: Получить структурированный список всех типов, доступных в библиотеке проекта (включая фейсплейты и скрипты) вместе с их версиями.
`get_master_copies`: Получить список мастер-копий (Master Copies) из библиотеки.
`get_plc_summary`: Получить сводную статистику по ПЛК (количество блоков, тегов, типы языков программирования, ошибки компиляции).
`get_project`: Получить доступ к открытому проекту/сессии TIA-Portal.
`plc_get_software_info`: Получить базовую информацию о программном обеспечении ПЛК.
`plc_get_software_tree`: Получить структуру ПО ПЛК в виде дерева (включает блоки, типы, теги, таблицы и источники).
`get_state`: Получить состояние подключения и среды выполнения TIA Portal.
`plc_get_tag_info`: Получить информацию о конкретном ПЛК теге.
`plc_get_tags`: Получить список всех тегов ПЛК.
`plc_get_tag_table_info`: Получить таблицу тегов ПЛК вместе с ее содержимым.
`plc_get_tag_tables`: Получить список таблиц тегов ПЛК.
`plc_get_type_info`: Получить информацию о типе данных ПЛК (UDT).
`plc_get_types`: Получить список всех типов данных ПЛК.
`plc_get_type_source`: Получить исходный код типа данных ПЛК.
`plc_get_watch_table_info`: Получить информацию о таблице наблюдения ПЛК, включая все её переменные и параметры отображения.
`plc_get_watch_tables`: Получить список таблиц наблюдения ПЛК.
`instantiate_master_copy`: Создать экземпляр мастер-копии (Master Copy) из библиотеки в проекте (например, блок или тип данных).
`plc_move_block`: Переместить программный блок в другую группу.
`plc_move_type`: Переместить тип данных ПЛК (UDT) в другую группу.
`open_global_library`: Открыть глобальную библиотеку (.al1x) в текущей сессии TIA Portal.
`open_project`: Открыть существующий проект или сессию TIA-Portal.
`open_tia_project`: Подключиться к TIA Portal (если еще не подключено) и открыть заданный проект/сессию.
`hw_plug_module`: Добавить (установить) новый аппаратный модуль в существующее устройство на определенную позицию.
`preview_import`: Предпросмотр результатов импорта (проверка конфликтов и возможных перезаписей перед фактическим импортом).
`plc_rename_block`: Переименовать программный блок. Блоки с защитой know-how отклоняются.
`plc_rename_tag_table`: Переименовать таблицу тегов ПЛК.
`plc_rename_type`: Переименовать тип данных ПЛК (UDT). Типы с защитой know-how отклоняются.
`plc_rename_watch_table`: Переименовать таблицу наблюдения ПЛК.
`plc_resolve_object_path`: Преобразовать простое имя объекта в полный путь, ища среди блоков, типов данных, тегов, таблиц и внешних источников.
`save_as_project`: Сохранить текущий проект/сессию TIA-Portal под новым именем.
`save_project`: Сохранить текущий проект/сессию TIA-Portal.
`hmi_set_unified_screen_item_event`: Установить обработчик события (например, Click) со скриптом JS для элемента экрана WinCC Unified.
`plc_where_used`: Показать, где используется (Cross-references) тег, блок, тип данных или таблица тегов (в виде простого списка).
`export_objects`: Универсальный инструмент для экспорта объектов ПЛК (блоков, типов, таблиц тегов) в файлы. Поддерживает форматы xml, document и source.
`import_objects`: Универсальный инструмент для импорта файлов в ПЛК. Поддерживает форматы xml, document и source.
`plc_manage_tag_table_entries`: Пакетное создание, обновление и удаление тегов и констант (CRUD-операции).
`plc_get_block_data`: Получить информацию о блоке, его интерфейс и исходный код за один вызов.
`hmi_manage_items`: Пакетное управление элементами экранов HMI (Upsert-логика).
`hmi_manage_unified_faceplate`: Создание и параметрирование фейсплейтов в WinCC Unified (включая привязку интерфейсных тегов).
