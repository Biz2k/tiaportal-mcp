## Правила

Действуют для всех пунктов; полные формулировки — в `docs/handoff/context.md`.

- Внутри транзакции TIA Portal нельзя «перехватить и продолжить»: после любого исключения
  Openness фиксация запрещена. Пакетные инструменты работают по принципу «всё или ничего»,
  всё проверяемое проверяется до обращения к Openness.
- Некоторые вызовы Openness закрывают TIA Portal вместе с несохранённым проектом. Вызов на
  новом виде объектов сначала пробуется отдельным скриптом (`tools/openness-probe.ps1`);
  известные опасные вызовы — в таблице в `docs/handoff/context.md`.
- Openness многое принимает молча и молча искажает. Записанное читать обратно и сравнивать.
- Прежде чем считать, что Openness чего-то не умеет, искать по всем его сборкам
  (`tools/openness-reflect.ps1 -Name ...`).
- PLCSIM запускает владелец; сервер его не запускает. Сетевые настройки ПК меняет владелец.
- Проверочный проект — `21474_SEVGOK_P2_v4_V21`. `TestProject` — проект тестировщика: перед
  изменяющим вызовом смотреть, какой проект открыт.
- Проверено вживую, проверено только тестами, не проверено — писать прямо.
- Каждая пересборка сервера требует от владельца подтверждения «Openness access». Разработку
  вести через `tools/inproc-call.ps1` (PowerShell доступ уже имеет), «дымовой» прогон — один раз
  на законченный кусок работы и по слову владельца.
- Инструмент для одного языка несёт язык в имени (`plc_get_lad_networks`); чувствительное —
  отдельными инструментами области `security`.

## Что невозможно через Openness V21

Выяснено и закрыто; здесь — чтобы не выяснять заново.

| Что | Почему |
|---|---|
| Пороги HMI-тега | `Thresholds.Create()`: «New thresholds are not supported» на всех типах данных |
| `DisplayName` HMI-тега | запись закрывает TIA Portal |
| Удаление и переименование модуля скриптов | у `HmiScriptModule` нет `Delete` |
| Чтение и создание циклов Unified | у `HmiSoftware` нет коллекции циклов; имя цикла при записи проверяет `Validate()` |
| Вид свойства интерфейса фейсплейта заранее | у `HmiFaceplateInterface` нет признака вида |
| Чтение списков, являющихся типами библиотеки | экспорт версии типа не содержит записей |
| Проверка имени рисунка в графическом списке | коллекция графики Unified недоступна; у элемента экрана рисунок проверяет `Validate()` |
| Отличить фейсплейт Advanced от Professional | один класс без признака системы |
| Таблица Expression конвертера значения | создание строки закрывает TIA Portal |
| Строки «только от» и «только до» таблицы диапазонов | `RangeType` только для чтения |
| Проверка синтаксиса скрипта и формулы Unified при записи | Openness сохраняет код с ошибкой дословно; ошибку называет только компиляция (`unified_compile`), а она запрещена внутри транзакции |
| Компиляция одного экрана или скрипта Unified | `ICompilable` есть только у устройства HMI |
| Компиляция только оборудования устройства | `Device.Compile()` компилирует оборудование вместе с программой |
| Экраны и элементы классического WinCC | нет объектной модели, только XML |
| Снять защиту проекта; убрать заданный пароль защиты блока от записи | в API нет обратных вызовов |
| Назначить ПК временный адрес в подсети устройства при загрузке | это делает только диалог TIA Portal |
| Обновить список «Accessible devices» | `GetAccessibleDevices()` отдаёт список, который обновляет только окно TIA Portal |
| Установить GSD-файл или пакет поддержки (HSP) | вызова нет; делается в TIA Portal (меню Options) |
| Выставить клиенту значение разрешения по умолчанию («Needs approval») | настройка принадлежит клиенту; сервер только делит инструменты по группам |
