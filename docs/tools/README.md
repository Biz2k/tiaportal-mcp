# Tool reference

Generated by `tools/make-tool-docs.ps1` from the tool definitions of the server; the `Description` attributes in the code are the source. A tool marked **write** changes the project and is only available when the server runs without `--read-only`; **session** tools only change the connection or the open project/session. Names with `/` in a path are written `%2F`.

- [General](general.md) - 24 tools. Connection, project and session tools.
- [PLC software](plc.md) - 71 tools. Blocks, data types, tags, tables, external sources, cross references and compile.
- [Hardware and network](hardware-network.md) - 17 tools. Devices, modules, subnets, IO systems and communication connections.
- [WinCC Unified](unified.md) - 35 tools. Screens, items, tags, scripts, logs, alarms, connections, lists and runtime settings.
- [Libraries](libraries.md) - 5 tools. The project library, global libraries and master copies.
- [Export and import](export-import.md) - 3 tools. Blocks, types and tag tables as XML, SIMATIC documents or source files.
- [Download](download.md) - 2 tools. Download targets and download to a PLC.
