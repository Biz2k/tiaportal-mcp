# WinCC Unified: что есть по умолчанию

Справочник для модели: какие имена принимает `unified_manage_items` и что уже есть в проекте до того, как
пользователь что-то создал. Проверено на TIA Portal V21 06.10.2026 на тестовом проекте Biz.

## Циклы HMI (Cycles)

В дереве HMI Unified: **Cycles**. По умолчанию семь циклов (единицы — миллисекунды):

| Имя | Время |
|---|---|
| `T100ms` | 100 мс |
| `T250ms` | 250 мс |
| `T500ms` | 500 мс |
| `T1s` | 1000 мс |
| `T2s` | 2000 мс |
| `T5s` | 5000 мс |
| `T10s` | 10000 мс |

Пользователь может добавить свои циклы (в тестовом проекте — `Custom cycle`, 3 секунды). Openness V21 **не отдаёт
циклы Unified-HMI** (у `HmiSoftware` нет свойства `Cycles`; класс `Siemens.Engineering.Hmi.Cycle` относится к
классическому WinCC), поэтому сервер не может ни прочитать список, ни создать цикл. Имя проверяет только Openness при записи `HmiLoggingTag.Cycle` (принимает цикл пользователя без учёта регистра, отклоняет неизвестное). См.
[`findings.md`](findings.md), раздел 16.

Где имя цикла участвует:

- архивный тег: `unified_manage_logging_tags`, свойство `Cycle` (только имена из таблицы; при режиме `Cyclic` не меньше 500 мс);
- триггер скрипта-динамизации: `"trigger": "T1s"` (названные циклы — готовые типы), либо
  `{"type": "CustomCycle", "cycle": "Custom cycle"}` для цикла пользователя. Имя пользовательского цикла Openness не
  проверяет: несуществующее принимается, и скрипт не запускается.

## Триггеры скрипта-динамизации

`Disabled`, `T100ms`, `T250ms`, `T500ms`, `T1s`, `T2s`, `T5s`, `T10s`, `CustomCycle`, `Tags`, `AutomaticTags`.
Новая скрипт-динамизация получает `AutomaticTags` (скрипт запускается при изменении тегов, которые он читает).
`Tags` требует список тегов; их существование сервер проверяет сам (Openness принимает любое имя).

## События элементов

Имена событий в Openness и подписи в интерфейсе TIA Portal отличаются. Подписи — с экрана Events кнопки (V21):

| Событие Openness (`events`) | Подпись в TIA Portal | Есть у |
|---|---|---|
| `Activated` | Activated | кнопка, поле ввода-вывода |
| `Deactivated` | Deactivated | кнопка, поле ввода-вывода |
| `Tapped` | Click left mouse button | кнопка, поле ввода-вывода |
| `KeyDown` | Press key | кнопка, поле ввода-вывода |
| `KeyUp` | Release key | кнопка, поле ввода-вывода |
| `Down` | Press | только кнопка |
| `Up` | Release | только кнопка |
| `ContextTapped` | Click right mouse button | кнопка, поле ввода-вывода |

Полный список событий каждого вида элемента сервер называет в ошибке при неизвестном имени
(`unified_get_screen_items` показывает уже заданные). Тип события кнопки — `HmiButtonEventType`
(`None, Activated, Deactivated, Tapped, KeyDown, KeyUp, Down, Up, ContextTapped`), поля ввода-вывода —
`HmiIOFieldEventType` (то же без `Down` и `Up`).

## События изменения свойства

В интерфейсе TIA Portal это не вкладка Events, а динамизация **Script** у подсвойства (например, у `ProcessValue`:
`Change` и `Quality code change`). В Openness это `PropertyEventHandlers` элемента: `propertyEvents` в
`unified_manage_items`, ключ `"ProcessValue"` (изменение значения) или `"ProcessValue.QualityCodeChange"` (для него
нужна привязка к тегу). Свойство должно существовать у элемента.

## Область глобальных определений

Одна на **все скрипт-динамизации экрана** и одна на **все события и события изменения свойств экрана**.
Запись `globalDefinitions` у одного скрипта меняет её у всех остальных; сервер говорит об этом в `notes`.
`async`, наоборот, свой у каждого скрипта.

## Конвертер значения (привязка к тегу, выражение)

- `formula` — формула, например `'Tag_1'*2+1` (включается флаг «формула», таблица отключается);
- `mapping` — таблица: `range` (строки `from`, `to`, `value`, `flashing`, `rate`, `alternate`), `singlebit` (две
  строки, `bit` 0 и 1), `none`. Таблицы `bitmask` и `expression` не поддерживаются: создание строки выражения
  закрывает TIA Portal, у строки bitmask нельзя выбрать маску.
- Косвенная адресация (`indirect`) — только для тега типа `String`/`WString`: он хранит имя читаемого тега.
- Скорости мигания: `Slow`, `Medium`, `Fast`. Условия мигания: `Never`, `Always`, `RangeViolation`. Мигание —
  только у свойств-цветов.
