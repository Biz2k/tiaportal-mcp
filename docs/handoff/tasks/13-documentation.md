# 13. Документация

Приоритет: низкий; делать, когда набор и имена инструментов перестанут меняться (после задач
01–03 и решения 12.1). Объём: средний. Раздел 5 плана.

## Пункты

- [x] **`src/TiaMcpServer/README.md`** использует имена инструментов до переименований (в
      начале файла стоит примечание об этом). Переписать вручную: автозамена портит описания
      методов `Portal`. Сверять с `docs/tools-list.txt` и с кодом, а не с памятью.
- [x] **`docs/tools/`** — по странице на область инструментов (ПЛК, оборудование и сеть,
      Unified, библиотеки, загрузка, экспорт и импорт): параметры, примеры вызовов, ограничения
      Openness. Источник правды — атрибуты `Description` в коде; полные определения
      инструментов выгружаются `tools/mcp-call.ps1 -DumpTools tools.jsonl`.
- [x] **`docs/recipes/`** — сценарии из нескольких инструментов: «создать экран с кнопкой и
      полем, привязанным к тегу ПЛК», «добавить ПЛК и подключить к подсети», «перенести блок
      между ПЛК». Каждый сценарий сначала выполнить вживую.
- [x] **`TODO.md` и план.** `TODO.md` частично устарел: в нём отмечены выполненными и
      невыполненными пункты, не совпадающие с кодом, и исторические имена `hmi_*`. Свести
      `TODO.md`, `docs/PLAN.md` и `docs/handoff/tasks/` к одному
      источнику: задачи живут в `docs/handoff/tasks/`, `TODO.md` — короткий указатель на них.
      Перед удалением чего-либо из `TODO.md` убедиться, что пункт есть в задачах или сделан.
- [x] **`Implemented_Tools.md`** — на русском, по строке на инструмент. Проверить, что каждый
      инструмент из `docs/tools-list.txt` в нём есть и нет лишних.
- [x] **`README.md` и `README_ru.md`** должны оставаться зеркальными: одинаковые разделы,
      одинаковые примеры. В начале каждого — ссылка на другой язык.

## Правила

- Окончания строк CRLF; у части файлов BOM — сохранять как есть (`tools/finish.ps1`).
- Не утверждать в документации того, что не проверено вживую; непроверенное помечать.
- Тексты для пользователя — без внутренних имён и сокращений, придуманных по ходу работы.
