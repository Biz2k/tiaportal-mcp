# 15. Отложено — не брать без прямого поручения Biz

## 15.1. Инструменты для LAD

Biz планирует вернуться к разработке инструментов работы с LAD (лестничная логика) через этот
сервер позже, с моделью Opus. **Не начинать.** Если по ходу другой задачи встретится что-то
относящееся к LAD (формат SimaticML сетей, шаблон в `plc_create_fb`), записать находку сюда.

Что уже есть по теме:

- `plc_create_fb` создаёт FB на LAD / FBD / STL из шаблона SimaticML (`Portal.Blocks.cs`);
  пространство имён интерфейса в шаблоне — `v5` (V21).
- `export_objects` / `import_objects` с форматом `xml` переносят блоки целиком как SimaticML.
- Насколько известно на 06.10.2026, сети и элементы LAD доступны в Openness только как XML
  блока. Это не проверялось отражением по всем сборкам — проверить первым делом
  (`tools/openness-reflect.ps1 -Name 'Network|Lad|Flg'`).

## 15.4. Из исходного отчёта тестирования, требует отдельного проектирования

- `changeId` и список затронутых объектов для каждой записи.
- Адресация объектов по идентификатору вместо пути.
- `dryRun` для изменяющих инструментов. Для загрузки невозможен в принципе (попытка прервать
  загрузку из обратного вызова закрыла TIA Portal); для остальных есть транзакции и
  `preview_import`.
- Матрица совместимости по версиям TIA Portal, Openness, HSP и GSD.
- Онлайн-диагностика, режим CPU, опрос состояния ПЛК.
